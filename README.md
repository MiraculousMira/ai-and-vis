# ai-and-vis

## Task
Classification of Muffins and Chihuahua.

Tag the dataset with spurious features and try to find the tags where it struggles on. Are there tags that lead to strong predictions without even showing a Muffin/Chihuahua?

#### Note
AI suggested to not do tagging but use heuristics and metrics for analysis, so we dropped the tagging idea.

## Models
- Resnet-50 retrained for 3 epochs in its penultimate layer

## Datasets
- [samuelcortinhas muffin-vs-chihuahua-image-classification](https://www.kaggle.com/datasets/samuelcortinhas/muffin-vs-chihuahua-image-classification)
