# Overview

Code is based on a **Python 3.12** installation. To run the code install requirements.txt with 
```bash
pip install -r requirements.txt
```

## Run Python files

The files **finetune**, **basic_analysis** and **shapley** are coded in a way that they should be on the same file level as the data folder with structure

```
data
|
|_ test
|   |
|   |___chihuahua
```
